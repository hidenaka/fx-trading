# ポートフォリオ戦略マネージャー Design

## Goal

複数通貨ペア（USD/JPY, EUR/USD, GBP/USD）で分散投資し、市場環境に応じて最適な戦略を自動選定・資金配分し、年間+20%リターン・最大-25%ドローダウンを目指す自動売買資産運用システムを構築する。

## Architecture

「ポートフォリオ戦略マネージャー」を中核に据え、4時間足の市場データから環境を検出し、トレンド相場時はトレンドフォロー戦略を、もみ合い相場時は反転戦略を自動選定。ケリー基準とボラティリティターゲティングで最適ロットを計算し、週次リバランスで資金配分を最適化する。

## Components

- `src/portfolio/market_regime.py`: 市場環境検出。ADX（14期間）でトレンド強度を測定。ADX>25でトレンド相場、ADX<20でもみ合い相場と判定。
- `src/portfolio/strategy_selector.py`: 環境に応じた戦略自動選定。トレンド時は`ma_macd`, `ma_cross`, `dow_theory`を選択。もみ合い時は`stochastic`, `ml_strategy`を選択。
- `src/portfolio/position_sizer.py`: ケリー基準（f* = (bp - q) / b）とボラティリティターゲティング（5%）を組み合わせたロット計算。
- `src/portfolio/rebalancer.py`: 週次（金曜日クローズ後）に各戦略・ペアのパフォーマンスを評価し、次週の資金配分を最適化。
- `src/portfolio/portfolio_manager.py`: 全体統合。複数戦略のシグナルを集約し、リスク管理を通じて最終エントリー/イグジットを判定。

## Data Flow（1取引サイクル）

```
[4Hローソク足更新]
    ↓
[MarketRegime] → ADXでトレンド強度を測定 → トレンド相場と判定
    ↓
[StrategySelector] → トレンドフォロー系（MA+MACD, MAクロス, Dow理論）を選択
    ↓
[各戦略でシグナル生成] → 3戦略がBUYを示唆
    ↓
[PortfolioManager] → 多数決でBUY確定
    ↓
[PositionSizer] → ボラティリティ5%ターゲットでロット計算
    ↓
[RiskManager] → 1%ルールで損切り設定
    ↓
[注文実行] → エントリー + 損切り/利確注文同時発行
    ↓
[Rebalancer] → 週末にパフォーマンスチェック、次週配分を調整
```

## Error Handling

| 失敗モード | 対応 |
|-----------|------|
| 全戦略がノーシグナル | ポジション維持または待機。無理なエントリーを防ぐ |
| 戦略間でシグナルが分裂（2buy/2sell） | PortfolioManagerが「両方スキップ」。確信がない時は動かない |
| 週次リバランスで全戦略が破綻 | 現金比率を上げ、次の週まで待機 |
| ボラティリティ急上昇 | PositionSizerが自動的にロット縮小。リスクを一定に保つ |
| 1ペアで大損失 | 他ペアでカバー。全体の1%ルールで総損失を抑制 |
| ADX計算不能（データ不足） | デフォルトで「もみ合い相場」と判定し、保守的な戦略を選択 |

## Testing Strategy

- **MarketRegimeテスト**: ADX>25の明確なトレンドデータとADX<15のもみ合いデータで正しく判定するか
- **StrategySelectorテスト**: 各レジームで正しい戦略セットが選ばれるか
- **PositionSizerテスト**: ケリー基準とボラターゲットの計算が数学的に正しいか
- **PortfolioManagerテスト**: 複数戦略のシグナルが正しく集約され、確信度閾値（例：3戦略中2つ以上が同方向）を満たすか
- **統合テスト**: 全モジュールを通した1週間分のシミュレーションで、ポートフォリオ全体の損益が整合するか

## 設定値

- **通貨ペア**: USD/JPY, EUR/USD, GBP/USD
- **時間足**: 4時間足（H4）メイン、日足（D1）でトレンド方向確認
- **目標リターン**: 年間+20%
- **最大許容ドローダウン**: -25%
- **1回のリスク**: 資金の1%
- **ボラティリティターゲット**: 5%
- **リバランス頻度**: 週次（金曜日）
- **確信度閾値**: 同一方向に3戦略中2つ以上がシグナル
