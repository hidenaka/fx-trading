# FX自動売買システム Design

## Goal

USD/JPYを中心としたFX市場において、複数のテクニカル戦略を同時にバックテスト・最適化・頑健性検証し、複合パフォーマンス指標で「今最も信頼できる戦略」を自動選定する軽量バックテスト＆評価フレームワークを構築する。

## Architecture

軽量pandasベースのバックテスト＆戦略評価フレームワーク。各FX理論を「戦略クラス」として実装し、複数戦略を同時にバックテスト → パラメーター最適化 → ウォークフォワード分析（WFA）検証 → 自動ランキング、というフローを自動化する。データ取得部分は初期から多通貨ペア対応に抽象化しており、後からEUR/USD、GBP/JPY、AUD/JPY等を追加可能。暗号資産（BTC等）も同じフレームワークで後から追加できる設計とする。

## Components

- `data/`: 市場データ取得・キャッシュ・前処理。USD/JPYの1H/4H/Dデータを取得し、将来的に多通貨ペア・暗号資産にも対応可能な抽象層を提供する。
- `strategies/`: 各FX理論に基づく戦略クラス。テンプレートパターンを採用し、新しい戦略の追加を容易にする。初期実装としてMA+MACD、ダウ理論ベース、ストキャスティクス+ローソク足パターンを想定。
- `engine/`: バックテスト実行エンジン。シグナルからトレードシミュレーションを行い、トレード履歴・エクイティカーブを出力する。
- `risk/`: リスク管理モジュール。1%ルールに基づくロット計算、損切り・利確・トレーリングストップの実行を行う。
- `optimizer/`: パラメーター最適化モジュール。並列グリッドサーチにより各戦略の最適パラメーターを探索する。
- `wfa/`: ウォークフォワード分析モジュール。時系列クロスバリデーションにより、過学習（Curve Fitting）を防ぎ、戦略の頑健性を検証する。
- `selector/`: 戦略自動選定モジュール。シャープレシオ、プロフィットファクター、最大ドローダウン等の複合スコアで戦略をランキングし、最適戦略を選定する。
- `reports/`: パフォーマンスレポート生成。エクイティカーブ、取引履歴、指標サマリーを出力する。

## Data Flow

```
[市場データ取得] → [複数戦略でシグナル生成] → [バックテストエンジンでシミュレート]
                                                          ↓
[最適戦略選定] ← [自動ランキング] ← [WFAで頑健性検証] ← [パフォーマンス指標計算]
                                                          ↓
                                              [グリッドサーチでパラメータ最適化]
```

1. 市場データ取得（USD/JPY 1H, 4H, D ※初期はUSD/JPYに集中）
2. 各戦略にデータを入力しシグナル生成（エントリー・イグジット）
3. エンジンがトレード履歴をシミュレート
4. リスク管理でロット・損切り・利確を計算
5. パフォーマンス指標（シャープレシオ、PF、MDD等）を計算
6. 最適化でパラメーターを探索
7. WFAで頑健性を検証
8. セレクターで最適戦略を選定
9. レポート出力

## Error Handling

| 失敗モード | 対応 |
|-----------|------|
| データ取得失敗（ネットワーク/API制限） | 3回リトライ後、ローカルキャッシュの最新データを使用 |
| データ欠損（休場・メンテナンス） | 前方フィルまたは線形補間で継続可能にする |
| ゼロ除算（ボラティリティ0、同一価格連続） | ガード節で回避。異常検出時はシグナル生成をスキップ |
| シグナル衝突（同時に買いと売い） | 優先ルール適用（トレンド方向優先）または両方スキップ |
| 過学習（オーバーフィッティング） | WFAで棄却。未来データで破綻した戦略は自動除外 |
| 資金不足（マージンコール相当） | ポジションサイズを自動縮小。極端な場合は取引停止 |

## Testing Strategy

- **ユニットテスト**: 各戦略のシグナル生成ロジックを「既知の価格パターン」で検証（例：ゴールデンクロス発生時に買いシグナルが出るか）
- **統合テスト**: バックテストエンジンが簡易な価格シーケンスで正しいトレード履歴・損益を計算するか（手計算と一致確認）
- **WFAテスト**: 時系列データの分割・検証ロジックが正しく機能するか
- **リスク管理テスト**: ロット計算、損切り・利確価格が正確に計算されるか
- **バックテスト整合性テスト**: 同一データ・同一パラメーターで再実行した結果が完全一致するか（非決定的処理の排除確認）

## 通貨ペア・時間足

- **メイン通貨ペア**: USD/JPY（初期集中）
- **時間足**: 1時間足（H1）をメイン、4時間足（H4）と日足（D1）でトレンド方向確認する多時間足分析
- **将来拡張**: EUR/USD, GBP/JPY, AUD/JPY等の追加を想定。データ取得部分は初期から多通貨対応とする。

## 暗号資産対応方針

- **初期段階**: FXに集中。ボラティリティ・ギャップ・レバレッジ差の課題があるため、システムが安定してから追加する。
- **設計**: フレームワーク自体は暗号資産（BTC等）も後から追加できるよう抽象化しておく。
